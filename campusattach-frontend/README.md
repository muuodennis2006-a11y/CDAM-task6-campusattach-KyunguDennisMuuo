# CampusAttach

## Student Attachment and Internship Opportunity Platform

CampusAttach is a web-based platform designed to help university students discover, apply for, and track attachment and internship opportunities.

The platform also provides organizations with a structured way to publish opportunities and manage student applications, while system administrators can manage users and moderate opportunities.

---

## Project Overview

CampusAttach was developed to provide a centralized platform for students searching for attachment and internship opportunities.

The system supports three main user roles:

- Student
- Organization
- System Administrator

The Task 3 implementation focuses on developing the Angular frontend and implementing the main user interfaces, navigation, forms, authentication flow, role-based access, and core workflows.

---

## Problem Statement

University students often struggle to find attachment and internship opportunities because information is scattered across WhatsApp groups, social media platforms, university notices, company websites, personal contacts, and other sources.

Students may also find it difficult to determine whether an opportunity matches their course, understand its requirements and deadline, and keep track of applications.

Organizations also lack a structured platform for publishing opportunities and managing student applications.

CampusAttach aims to provide a centralized platform for organizing these activities.

---

## Objectives

The main objectives of CampusAttach are to:

- Allow students to create and manage their profiles.
- Allow students to browse attachment and internship opportunities.
- Allow students to search and filter opportunities.
- Allow students to view detailed opportunity information.
- Allow students to apply for opportunities.
- Allow students to track application status.
- Allow organizations to create and manage opportunities.
- Allow organizations to review student applications.
- Allow organizations to update application status.
- Allow administrators to manage users.
- Allow administrators to moderate opportunities.
- Provide secure role-based access to system features.
